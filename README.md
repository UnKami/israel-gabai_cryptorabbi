# CryptoRabbi – מסע קריפטו חם ומבוקר

אתר חד-עמודי שנבנה עם Vite + React כדי לספר את מסעו של ישראל בעולם הקריפטו,
ולהציע כלים מותאמים לקהילה החרדית. הממשק פועל כברירת מחדל בעברית, בכיוון
כתיבה מימין לשמאל, וכולל אנימציות גלילה חלקות.

## התחלה מהירה

```bash
npm install
npm run dev
```

- `npm run dev` מפעיל שרת פיתוח (ברירת מחדל: http://localhost:5173).
- `npm run build` יוצר גרסת הפצה לתיקיית `dist/`.
- `npm run preview` מאפשר לבדוק את גרסת ההפצה באופן מקומי.

## מבנה התיקיות

- `src/pages/index.jsx` – פריסת הגלילה הראשית, כולל סיפור המסע, לוחות זמנים
  וכלי קהילה.
- `src/components/Navigation.jsx` – תפריט ניווט דביק עם קישורים לכל הסקשנים.
- `src/components/CallToAction.jsx` – קריאה לפעולה בעלת ניגודיות גבוהה.
- `src/styles/global.css` – טיפוגרפיה עברית, RTL גלובלי, וצללים חמים
  רספונסיביים.
- `src/pages/index.module.css` – סגנון ממוקד לדף הבית, כולל שכבות רקע ותצוגות
  רספונסיביות.
- `public/assets/hero-abstract.svg` – רקע שחור-לבן מופשט עבור אזור הגיבור.

## החלטות עיצוב

- **ניגודיות חמה**: שימוש ברקע כהה עם הברקות בהירות כדי לשמור על קריאות
  גבוהה, בהתאם לאסתטיקה של התמונה המופשטת.
- **שפת אם ו-RTL**: כל ה-HTML וה-CSS מוגדרים ל-he ו-rtl כברירת מחדל, והטקסט
  מנוסח בעברית תקנית.
- **אנימציות הדרגתיות**: הספרייה Framer Motion מוסיפה כניסות רכות ורמות
  עומק בעמוד מבוסס גלילה.
- **רספונסיביות**: גרידים וגודל טיפוגרפי דינמיים מבטיחים חוויה חלקה בנייד
  ובדסקטופ.

## פרטי ייצוא והפצה

- ניתן לפרוס את האתר בכל שירות סטטי התומך ב-Vite (Netlify, Vercel,
  Cloudflare Pages וכו').
- יש לוודא הגדרת `dir="rtl"` ו-`lang="he"` בקובץ `index.html` בעת שימוש
  במסגרת פריסה מותאמת אישית.
- מומלץ להפעיל `npm run build` כחלק מתהליך CI כדי לוודא שלמות הקומפילציה.

## קרדיטים לנכסים

- תמונת הרקע `hero-abstract.svg` נוצרה במיוחד עבור הפרויקט ומשוחררת לשימוש
  במסגרת MIT יחד עם הקוד.
- גופני Google Fonts (Assistant, Rubik) נטענים באמצעות CDN של Google בהתאם
  לרישיון הפתוח שלהם.
